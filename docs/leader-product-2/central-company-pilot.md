# Local Central / Company protocol pilot — 2026-11-17

Implemented in dev/platform-pilot/pilot.cjs; `npm run test:platform-pilot` uses real loopback HTTP listeners on ephemeral ports and closes them after tests. No imports from legacy runtime, .env, Prisma, Redis, 1C or deployment configuration. Fixture-only users/password/data, ephemeral tokens and Ed25519 keys; no public CLI listener or external endpoint defaults. Do not expose this harness as a service.

Central maps alice to alpha and bob to beta; session cannot request another company's audience. Discovery returns company-specific endpoint and signed pinned release set (alpha-1: qr/help 1.0.0; beta-4: qr 2.0.0). Opaque restricted tokens expire after 60s; central tracks session revocation. Company requests authenticate through an HTTP call to Central on EVERY request, with company-specific service credentials. Positive results are never cached. Central failure returns 503 even after prior authorization; universal session tokens and wrong-company/artifact audiences are rejected. Fixture record ownership enforced server-side.

Artifact service requires dedicated artifact audience and company/module entitlement, introspects online, and returns digest-addressed immutable bytes only for the authorized company. Manifests signed over exact payload bytes; no universal token forwarded to caller-selected URLs. Fixtures are byte probes, not executable business modules and not a production storage implementation.

Evidence: `node --test dev/platform-pilot/pilot.test.cjs` exit 0, 4 integration tests / 106.8ms. Verified two discovery/release assignments and signatures, repeated network introspection count, central-outage rejection after positive access, global/wrong audience/company denial, object lookup denial, forged introspection service denial, private artifact hash/access/tenant checks, online revoke propagation to discovery/Company/artifacts. This is real local HTTP integration, not PostgreSQL/native/device/load evidence.

Do not call the pilot a ready SaaS. Existing production-like legacy API remains unexposed and unchanged by this slice, including known socket/scheduler findings.
